# 장애 회고: 로그인 게이트웨이 세션 처리 버그로 이 타이틀만 접속 실패

작성: 서버개발팀 / 작성일: 2026-10-15

## 사건 개요

이 타이틀에서 로그인이 되지 않고 접속이 실패하는 장애가 있었다. 증상은 로그인 서버, 이하 게이트웨이에서 나타났다. 원인은 게이트웨이의 세션 처리 로직 버그로 정리했다. 분류상 '게임 로그인 서버 장애'에 해당한다.

## 타임라인

먼저 '로그인 불가, 접속 장애' 신고가 들어왔다. 이런 증상의 원인 후보는 여러 가지인데, 게임 로그인 서버 장애는 그중 가능성이 중간 정도인 후보다. 그래서 바로 단정하지 않고 두 가지를 확인했다. 확인이 끝난 뒤에는 이 원인일 때 여는 대응 절차를 순서대로 열었다.

## 확인한 근거

첫째, 다른 타이틀의 로그인 상태를 확인했다. 다른 타이틀 로그인은 정상이었고, 문제가 이 타이틀에 한정된다는 점이 드러났다. 게이트웨이는 통합 계정 인증에 의존하므로 인증에 문제가 생기면 영향이 간다. 이번에는 다른 타이틀이 정상이어서 이 타이틀 쪽 게이트웨이 문제로 좁힐 수 있었다.

둘째, 서버 오류 로그를 조회했다. 게이트웨이에 증상과 관련된 오류 로그가 남아 있었다. 두 결과는 게임 로그인 서버 장애일 때 예상되는 모습과 일치했다.

## 원인

게이트웨이의 로직 쪽 문제, 구체적으로는 세션 처리 버그다. 이 때문에 이 타이틀만 접속이 실패했다.

## 담당

게이트웨이의 로직은 서버개발팀이 맡는다. 이번 건의 수정과 반영도 서버개발팀 소관이다.

## 조치

게임 로그인 서버 장애가 원인일 때 여는 절차 네 가지를 모두 열었다.

1. 긴급 공지
2. 긴급 점검
3. 롤백
4. 원인 수정과 반영

## 재발 방지

- 로그인 불가 증상이 들어오면 다른 타이틀 로그인 상태와 서버 오류 로그를 먼저 확인하는 순서를 유지한다.
- 게이트웨이 로직을 바꿀 때는 세션 처리 경로를 변경 검토 항목에 넣는다.
- 통합 계정 인증은 게이트웨이가 의존하는 대상이므로, 비슷한 증상에서는 인증 쪽 이상 여부도 함께 본다.
