박OO(고객지원팀): 문의 티켓이 벌써 열 건 넘었어요. 공지 나가야 하면 말씀해 주세요.
김OO(운영팀): 공지는 원인 좁히고 나서요. 일단 이게 게이트웨이 단독 문제인지부터 봐야 해요.
최OO(운영팀): 게이트웨이는 통합 계정 인증에 의존하잖아요. 인증에 문제가 생기면 게이트웨이까지 영향이 오니까, 그쪽 먼저 의심해 봐야 할 듯해요.
이OO(QA팀): 그럼 공통 계정 인증 장애인지부터 가려야겠네요. 어떻게 확인하죠?
김OO(운영팀): 다른 타이틀 로그인 상태 확인하면 돼요. 거기도 같이 안 되면 공통 계정 인증 장애일 가능성이 높고, 거기만 멀쩡하면 게이트웨이 쪽을 봐야죠.
정OO(QA팀): 아 그렇네요. 제가 다른 타이틀 계정 갖고 있으니까 지금 해볼게요.
박OO(고객지원팀): 근데 그거 확인하는 동안 티켓 답변은 뭐라고 드려요? "확인 중"만 계속 쓰기도 좀 그래서요.
김OO(운영팀): "현재 로그인 관련 상태를 확인하고 있다" 정도로만 해주세요. 원인은 아직 쓰지 마시고요.
최OO(운영팀): 그나저나 점심 먹고 오니까 이런 일이 터지네요. 제가 자리 비우면 꼭 이래요.
이OO(QA팀): 그건 최OO님 탓 맞는 것 같습니다 ㅋㅋ
최OO(운영팀): 억울합니다. 저번 주에는 제가 있었는데도 터졌잖아요.
정OO(QA팀): 다른 타이틀 로그인 테스트 중인데 로딩이 좀 길어요. 아직 결과 안 나왔어요.
박OO(고객지원팀): 혹시 제가 아까 접속 안 된다고 한 유저 계정으로도 해볼까요? 그 유저는 다른 타이틀도 한다고 했던 것 같아요.
김OO(운영팀): 그건 아니에요, 박OO님. 유저 계정 말고 테스트 계정으로 하는 게 맞아요. 개인 계정 건드리면 안 돼요.

정OO(QA팀): 다른 타이틀 로그인 결과 나왔어요. 저는 지금 두 번 시도했는데 둘 다 실패입니다.
