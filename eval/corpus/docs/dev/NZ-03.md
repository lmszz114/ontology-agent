# 신규 직원 온보딩 체크리스트

작성일: 2026-10-15

입사 첫 주에 확인할 항목을 정리한 문서입니다. 하나씩 끝낼 때마다 체크해 주세요.

## 입사 첫날

- [ ] 인사팀에서 사원증과 보안 출입 카드를 받는다.
- [ ] 자리에 비치된 노트북과 모니터를 점검한다. 케이블 정리는 직접 하면 된다.
- [ ] 사내 메신저에 가입하고 프로필 사진을 등록한다.
- [ ] 점심시간에 같은 팀 동료와 식사한다. 식권은 첫날 지급된다.

## 첫 주 안에

- [ ] 근무 시간 기록 방법을 익히고 하루 일과를 기록해 본다.
- [ ] 멘토 역할을 맡은 김OO 선배와 30분 면담을 한다.
- [ ] 정보 보호 교육 영상을 시청하고 확인 퀴즈를 제출한다.
- [ ] 휴가 신청과 경비 정산 절차를 읽어 둔다.
- [ ] 사내 도서관에서 대출 카드를 만든다.

## 첫 달 안에

- [ ] 팀 회의에 한 번 이상 참석해 자기소개를 한다.
- [ ] 입사 한 달 소감을 짧게 적어 인사팀에 전달한다.

모르는 점은 혼자 고민하지 말고 멘토나 인사팀에 편하게 물어보세요.
