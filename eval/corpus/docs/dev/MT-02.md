# 회의록 MT-02

- 일시: 2024-02-14
- 참석 팀: 서버개발팀
- 작성: 김OO

## 안건

1. 이벤트 시스템 설정 작업 담당 확인
2. 게임 데이터 테이블 변경 시 확인 사항 정리

## 논의

이벤트 시스템의 설정은 서버개발팀이 맡고 있다. 이벤트를 열거나 조정할 때 설정 값을 서버개발팀이 직접 넣는 방식이며, 이번 회의에서도 이 방식을 그대로 두기로 했다. 설정 작업 요청이 들어오면 서버개발팀 안에서 받아 처리하므로, 요청 창구가 하나인 점이 편하다는 의견이 나왔다.

다만 이벤트 시스템이 게임 데이터 테이블에 의존한다는 점이 짚였다. 테이블에 문제가 생기면 이벤트 시스템에도 영향이 간다. 그래서 설정을 넣는 쪽에서는 자기가 입력한 값만 볼 것이 아니라, 그 값이 기대는 테이블이 정상인지도 함께 봐야 한다는 의견이 있었다. 설정 자체에 오류가 없어도 테이블이 어긋나 있으면 이벤트가 정상적으로 돌지 않을 수 있기 때문이다.

## 결정

- 이벤트 시스템 설정은 계속 서버개발팀이 직접 입력한다.
- 설정을 넣기 전에 관련 게임 데이터 테이블 상태를 먼저 확인한다.
- 이벤트에 이상이 보이면 설정 값과 함께 게임 데이터 테이블도 점검 대상으로 본다.

## 후속 작업

- 설정 입력 전 테이블 확인 항목을 정리한다. (담당: 김OO)
- 이벤트 이상 발생 시 점검 순서를 문서로 남긴다. (담당: 서버개발팀 전원)
- 다음 회의에서 정리된 확인 항목을 검토한다.
