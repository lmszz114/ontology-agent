# 장애 회고: 공성전 시간에 서버 자원이 모자라 렉이 난 사건

작성: 2026-10-15 / 작성 팀: 인프라 운영

## 사건 개요

공성전이 진행되는 시간에 서버 인프라에서 렉이 발생했다. 증상은 '대규모 콘텐츠 중 서버 과부하'로 분류했다. 이런 증상에서는 서버 자원 부족이 원인일 가능성이 높은 편이다. 이번에도 그 후보를 가장 먼저 의심했다.

## 타임라인

1. 공성전이 시작된 뒤 서버 인프라 쪽에서 렉이 나타났다.
2. 증상이 대규모 콘텐츠 중 과부하와 같다고 보고 서버 자원 부족을 1순위 원인 후보로 올렸다.
3. 자원과 네트워크 지표를 조회해서 후보를 검증했다.
4. 콘텐츠 일정과 렉 발생 시점을 대조했다.
5. 두 확인이 모두 후보와 맞아떨어져 원인을 서버 자원 부족으로 판단하고, 대응 절차를 열었다.

## 확인한 근거

근거는 두 가지다.

첫째, 자원·네트워크 지표 조회 결과 서버 인프라의 자원 지표가 한계에 가깝거나 한계를 넘은 상태였다. 서버 자원 부족이 원인일 때 기대하는 모습과 같다.

둘째, 콘텐츠 일정(월드보스, 공성전 시간)과 대조해 보니 렉이 난 때가 대규모 콘텐츠가 진행되던 시간과 겹쳤다. 이것도 이 원인일 때 나오는 결과다.

## 원인

원인은 서버 자원 부족이다. 이는 서버 인프라의 운영 쪽 문제로 분류한다. 대규모 콘텐츠가 몰리는 시간에 서버 인프라의 자원이 감당할 수 있는 한계에 닿아 과부하와 렉으로 이어졌다.

## 담당

서버 인프라의 운영은 인프라 운영이 맡고 있다. 이번 건도 인프라 운영이 주관해서 원인 확인부터 후속 절차까지 처리한다.

## 조치

서버 자원 부족이 원인이므로 아래 세 절차를 열었다.

- 긴급 공지: 이용자에게 상황을 알린다.
- 긴급 점검: 서버 인프라를 점검한다.
- 원인 수정과 반영: 확인된 원인을 고쳐서 서버 인프라에 반영한다.

## 재발 방지

대규모 콘텐츠 중 과부하 증상이 다시 보고되면 같은 순서로 대응한다. 먼저 자원·네트워크 지표를 조회하고, 이어서 월드보스·공성전 같은 콘텐츠 일정과 대조한다. 두 결과가 이번처럼 나오면 서버 자원 부족으로 보고 긴급 공지, 긴급 점검, 원인 수정과 반영 절차를 바로 연다. 인프라 운영은 이 확인 순서를 이후 장애 대응의 기본으로 삼는다.
