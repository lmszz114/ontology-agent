# UI 개편 사용자 조사 결과

작성일: 2026-10-15

## 조사 개요
이번 조사는 개편 시안을 본 이용자들의 첫인상과 사용 편의를 살피려는 목적으로 진행했다. 응답자는 신규 이용자와 오래 접속한 이용자로 나누어 모았고, 시안 화면을 보여 준 뒤 설문과 짧은 대면 인터뷰를 병행했다.

## 주요 결과
- 메뉴 구성: 하단 메뉴를 한 줄로 묶은 구성에 호의적인 답이 많았다. 특히 신규 이용자는 처음 보는 아이콘도 금방 이해했다고 답했다.
- 글자 크기: 퀘스트 목록의 글자가 작다는 의견이 여러 번 나왔다. 오래 접속한 이용자일수록 이 의견이 두드러졌다.
- 색상 대비: 어두운 배경 위의 회색 안내 문구는 읽기 어렵다는 지적이 있었다.
- 길 찾기: 지도 창의 필터 위치가 바뀌어 처음에는 헤맸다는 응답이 있었으나, 두세 번 써 보면 익숙해진다는 답도 함께 있었다.

## 다음 단계
김OO이 인터뷰 기록을 정리해 공유할 예정이다. 글자 크기와 색상 대비에 관한 의견은 시안 수정 때 우선 검토하고, 수정안으로 짧은 재조사를 한 번 더 진행한다.
