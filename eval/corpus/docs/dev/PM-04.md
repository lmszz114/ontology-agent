# 장애 회고: 던전 몬스터 체력 값을 잘못 넣은 테이블 오류

## 사건 개요

업데이트 직후 던전 콘텐츠에서 오류가 나타났다. 던전 몬스터의 체력 값이 잘못 들어간 것이 원인이었고, 문제의 뿌리는 데이터 테이블의 콘텐츠 영역 값이었다. 이 글은 콘텐츠 기획이 당시 상황을 되짚고 같은 일이 반복되지 않도록 정리한 회고다. 작성일은 2026-10-15이다.

## 타임라인

업데이트가 나간 뒤 던전에서 이상 증상이 보고되었다. "업데이트 후 콘텐츠 오류"라는 증상은 원인 후보가 여럿이지만, 그중 콘텐츠 테이블 값 오류가 가장 먼저 의심되는 편이다. 이런 증상에서는 이쪽일 가능성이 높은 편이기 때문이다. 그래서 가장 먼저 이 후보부터 확인했고, 두 가지 근거로 가설이 맞는다는 것을 확인했다. 확인이 끝난 뒤에는 롤백 절차를 열었고, 이어서 원인 수정과 반영 절차를 열어 마무리했다.

## 확인한 근거

근거는 두 가지였다.

첫째, 데이터 테이블 변경 이력을 조회했다. 증상이 시작되기 전에 해당 콘텐츠 테이블을 바꾼 이력이 남아 있었다. 증상보다 변경이 앞섰다는 점이 이 원인일 때 기대되는 결과와 일치했다.

둘째, QA 재현 확인을 했다. QA가 같은 조건에서 증상을 재현했다. 우연한 일회성 현상이 아니라 특정 조건에서 반복되는 문제임을 여기서 확인했다.

## 원인

던전 몬스터의 체력 값이 데이터 테이블에 잘못 입력된 채 업데이트에 포함되었다. 이 값은 데이터 테이블 가운데서도 콘텐츠 영역의 데이터에 속한다. 코드나 인프라가 아니라 콘텐츠 데이터 쪽 문제라는 뜻이다.

## 담당

데이터 테이블의 콘텐츠 영역 데이터는 콘텐츠 기획이 맡는다. 따라서 이번 건의 책임과 수정 주체도 콘텐츠 기획이다. 값을 입력하고 검수하는 과정에서 걸러 내지 못한 점은 우리 팀이 안고 가야 할 부분이다.

## 조치

문제가 된 변경을 되돌리는 롤백을 먼저 진행해 증상이 더 퍼지지 않게 했다. 그 뒤 원인 수정과 반영 절차로 넘어가 체력 값을 바로잡아 다시 반영했다.

## 재발 방지

- 콘텐츠 테이블을 바꿀 때는 변경 이력이 남는지 확인하고, 업데이트 전에 값을 한 번 더 점검한다.
- 업데이트 후 콘텐츠 오류가 보고되면 변경 이력 조회와 QA 재현 확인을 짝으로 돌려 원인을 빠르게 좁힌다.
- 데이터 테이블은 로그 수집에 의존한다. 로그 수집에 문제가 생기면 데이터 테이블에도 영향이 가므로, 원인을 분리할 때 로그 수집 상태도 함께 염두에 둔다.
