# 사운드 리소스 관리 규칙

2026-10-15 기준으로, 사운드 리소스를 보관하고 수정할 때 지켜야 할 규칙을 정리한다.

## 파일 이름
파일 이름에는 소문자 영문, 숫자, 밑줄만 쓴다. 형식은 분류_대상_번호이며, 예를 들면 sfx_door_01처럼 짓는다. 공백과 한글은 넣지 않는다.

## 형식과 음량
효과음과 대사는 48kHz 16비트 WAV로 보관한다. 대사 파일의 채널은 모노로 하고, 효과음은 필요할 때만 스테레오로 둔다. 여기서 채널은 소리가 나오는 좌우 트랙을 뜻한다. 음량은 효과음 평균 -18 LUFS를 기준으로 맞추며, 최대 음량이 -1dB를 넘지 않게 한다.

## 버전 표기
파일을 고치면 이름 끝에 _v2, _v3처럼 버전을 붙이고, 이전 버전은 보관 폴더로 옮긴다. 기존 파일을 같은 이름으로 덮어쓰지 않는다.

## 삭제
쓰이지 않게 된 파일은 곧바로 지우지 않고 폐기 폴더에서 30일 동안 둔 뒤 삭제한다. 이 기간에는 파일을 되살릴 수 있다.
