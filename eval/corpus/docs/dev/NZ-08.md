# 사운드 리소스 관리 규칙

작성일: 2026-10-15

## 1. 파일 이름
파일명은 소문자 영문과 밑줄만 쓴다. 분류, 대상, 번호 순서로 적는다. 예를 들면 bgm_forest_loop_01.wav, sfx_sword_hit_03.wav 같은 식이다.

## 2. 포맷과 음량
원본은 48kHz, 24bit WAV로 보관한다. 배경음은 -18 LUFS 근처로 맞추고, 효과음은 피크가 -3dB를 넘지 않게 한다. 소리가 찌그러져 들리는 파일은 등록하지 않는다.

## 3. 폴더 구성
폴더는 bgm, sfx, voice, ui 네 갈래로 나눈다. 작업 중인 임시 파일은 각 폴더 안에 두지 말고 _draft 폴더에 모아 둔다.

## 4. 수정과 정리
수정본은 파일명 끝에 _v2, _v3처럼 붙인다. 이전 버전은 _old 폴더로 옮기고, 그곳에 들어간 지 90일이 지난 파일은 정리한다. 반복 재생되는 음원은 이음매에서 소리가 튀거나 끊기지 않는지 헤드폰으로 한 번 들어 본 뒤 등록한다.
