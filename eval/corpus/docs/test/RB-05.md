# 런북: 긴급 점검

작성: 인프라운영팀 / 작성 시점: 2026-10-15

## 이 절차를 여는 경우

원인이 다음 중 하나로 파악되면 긴급 점검 절차를 연다. 공통 계정 인증 장애, 게임 로그인 서버 장애, 서버 인프라 장애, 서버 적용 로직 오류가 여기에 해당한다. 원인이 아직 확정되지 않았더라도 증상이 위 넷 중 하나와 부합하면 먼저 절차를 열고, 진행하면서 원인을 좁혀 간다. 이 문서에 적지 않은 원인은 이 문서가 다루는 범위가 아니므로, 절차를 열지는 별도로 판단한다.

## 단계

1. **상황 파악**: 장애 증상과 발생 시각, 영향을 받는 범위를 확인해 기록한다. 이때 위 네 가지 원인 중 어느 쪽에 가까운지 함께 적어 둔다.
2. **절차 개시 선언**: 사내 대응 채널에 긴급 점검 절차를 연다고 알리고, 이후 진행 상황은 같은 채널에 모은다.
3. **점검 공지**: 이용자에게 긴급 점검 중임을 공지한다. 원인을 확정하지 못했다면 확인된 사실만 적고, 추측은 쓰지 않는다.
4. **원인별 복구 작업**: 확인된 원인에 맞는 복구를 진행한다. 인증, 로그인 서버, 인프라, 적용 로직 중 어디에서 문제가 났는지에 따라 작업 대상이 달라진다.
5. **정상 동작 확인**: 복구 후 접속과 로그인, 기본 플레이가 정상인지 직접 확인한다.
6. **점검 종료와 공지**: 확인이 끝나면 점검을 종료하고 이용자에게 알린다.
7. **사후 정리**: 경위와 조치 내용을 기록으로 남긴다.

## 주의 사항

- 점검 중 알게 된 내용은 대응 채널에 즉시 공유해 작업자 사이에 정보가 어긋나지 않게 한다.
- 원인이 중간에 바뀌면 기록과 공지를 함께 고친다.
- 복구 작업 전후의 상태를 남겨 두어야 사후 정리를 정확히 할 수 있다.
- 정상 동작을 확인하기 전에는 점검 종료를 공지하지 않는다.
