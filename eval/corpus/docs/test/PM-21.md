# 장애 회고: 월드보스 판정 처리 로직이 비효율적이라 렉이 난 사건

작성일: 2026-10-15 / 작성: 서버개발팀

## 사건 개요

월드보스 같은 대규모 콘텐츠가 진행되는 동안 월드 서버에서 과부하 증상이 나타나 유저들이 렉을 겪었다. 이런 증상의 원인 후보는 여럿이다. 그중 콘텐츠 처리 로직의 비효율은 가능성이 중간쯤으로 보는 후보였고, 이번 건의 실제 원인이 되었다. 아래에 경과와 근거를 남긴다.

## 타임라인

먼저 월드보스 시간대에 서버가 무거워진다는 증상이 확인되었다. 이어 원인 후보를 좁히려고 세 가지를 차례로 살폈다. 인프라의 자원과 네트워크 지표를 조회했고, 서버 오류 로그를 조회했으며, 콘텐츠 일정을 대조했다. 세 결과가 모두 로직 비효율 쪽을 가리켜 원인을 확정했다. 이후 긴급 공지와 원인 수정 및 반영 절차를 열었다.

## 확인한 근거

근거는 세 가지다.

- 자원과 네트워크 지표를 보니 서버 인프라의 자원에는 여유가 있었다. 장비가 모자라서 생긴 문제가 아니라는 뜻이다.
- 서버 오류 로그에는 특정 콘텐츠의 처리가 지연되었다는 기록이 남아 있었다.
- 콘텐츠 일정을 대조해 보니 렉이 난 시간이 월드보스나 공성전 같은 대규모 콘텐츠의 진행 시간과 겹쳤다.

자원은 남는데 특정 콘텐츠에서만 처리가 밀리고, 그 시간이 대규모 콘텐츠와 일치한다. 이 조합은 로직 비효율이 원인일 때 나타나는 전형적인 모습이다. 참고로 월드 서버는 게임 DB에 의존하기 때문에 DB에 문제가 생겨도 월드 서버에 영향이 간다. 다만 이번 건은 위 근거대로 월드 서버 로직 쪽 문제로 정리했다.

## 원인

월드보스 판정을 포함한 콘텐츠 처리 로직이 비효율적으로 짜여 있었다. 대규모 콘텐츠로 처리량이 몰리는 순간 이 로직이 병목이 되어 월드 서버 전체가 느려졌다.

## 담당

월드 서버의 로직은 서버개발팀이 맡는다. 이번 수정과 반영도 서버개발팀의 일이다.

## 조치

원인이 콘텐츠 처리 로직의 비효율로 확정되었으므로 두 절차를 열었다.

1. 긴급 공지: 렉 상황을 유저에게 알리는 절차다.
2. 원인 수정과 반영: 비효율적인 처리 로직을 고쳐 월드 서버에 반영하는 절차다.

## 재발 방지

대규모 콘텐츠 중 서버 과부하 증상이 다시 나오면 같은 순서로 확인한다. 먼저 자원과 네트워크 지표에 여유가 있는지 보고, 오류 로그에서 특정 콘텐츠의 처리 지연이 있는지 본다. 마지막으로 콘텐츠 일정과 시간이 겹치는지 대조한다. 세 가지가 모두 맞으면 로직 비효율부터 의심하면 된다. 게임 DB 쪽 문제도 월드 서버에 영향을 주므로, 근거가 어긋날 때는 이쪽도 함께 살핀다.
