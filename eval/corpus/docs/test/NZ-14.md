# 서버실 냉방기 교체 일정 안내

작성일: 2026-10-15

사내 서버실에 설치된 냉방기의 노후 교체 작업 일정을 안내합니다. 이 문서는 건물 설비 교체에 관한 내용이며, 최근 게임 서비스에서 발생한 서버 장애와는 관련이 없습니다. 여기서 말하는 서버실은 사내 건물 안의 물리 공간을 뜻합니다.

## 일정

- 10월 마지막 주 평일 오전: 기존 냉방기 철거
- 같은 주 오후: 신규 냉방기 반입 및 설치
- 11월 첫째 주: 시운전과 실내 온도 확인

작업 시간에는 서버실 출입이 제한되며, 소음과 진동이 있을 수 있습니다. 출입이 필요한 경우 작업 전날까지 미리 알려 주십시오.
