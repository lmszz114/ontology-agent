# 런북: 롤백

작성: 서버개발팀 / 작성일: 2026-10-15

## 언제 쓰는가

이 문서는 서비스에 반영된 변경을 이전 상태로 되돌려야 할 때 참고한다. 지금까지 확인된 롤백 개시 원인은 네 가지다. 게임 로그인 서버 장애가 발생했을 때, 콘텐츠 테이블 값 오류가 확인되었을 때, 서버 적용 로직 오류가 확인되었을 때, 복사 버그가 확인되었을 때 롤백 절차를 연다. 이 네 가지는 현재까지 정리된 사례일 뿐이므로, 목록에 없는 상황이라도 판단에 따라 이 절차를 검토할 수 있다.

## 단계

1. 현상을 확인하고, 위 네 가지 원인 중 어디에 가까운지 분류한다. 분류 결과는 대응 기록의 첫 줄에 남긴다.
2. 되돌릴 대상과 범위를 정한다. 어느 변경부터 되돌릴지, 직전 정상 시점이 언제인지를 이때 확정한다.
3. 관련 담당자에게 롤백 시작을 알린다. 실행 전에 범위를 한 번 더 읽어 서로 맞는지 확인한다.
4. 확정한 범위대로 롤백을 실행한다. 중간에 범위를 임의로 바꾸지 않는다.
5. 실행이 끝나면 문제가 된 증상이 사라졌는지 확인한다. 로그인 장애라면 접속 상태를, 테이블 값이나 적용 로직 오류라면 해당 값과 동작을, 복사 버그라면 같은 재현 경로를 다시 점검한다.
6. 결과와 실행 시각, 되돌린 범위를 기록하고 관련자에게 공유한다.

## 주의 사항

- 원인이 분명하지 않더라도 분류를 미루지 말고, 우선 가장 가까운 원인으로 적은 뒤 확인되는 대로 고쳐 쓴다.
- 롤백 범위는 실행 전에 확정한다. 실행 도중 범위를 넓히거나 줄이면 어디까지 되돌렸는지 추적하기 어렵다.
- 롤백이 끝났다고 원인 조사까지 끝난 것은 아니다. 원인 확인과 재발 방지 논의는 롤백 이후에 별도로 진행한다.
- 이 문서에 없는 판단이 필요하면 서버개발팀에 문의한다.
