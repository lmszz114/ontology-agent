# 회의록 MT-04

작성일: 2026-10-28
회의 성격: 담당 조정 회의
참석 팀: 콘텐츠기획팀, 시스템기획팀

## 안건

- 데이터 테이블의 영역별 담당 구분

## 논의

데이터 테이블은 지금까지 한 파일 안에 여러 성격의 값이 섞여 있어, 수정이 필요할 때 어느 팀에 요청해야 하는지 불분명하다는 의견이 나왔다. 이에 따라 테이블을 콘텐츠 영역과 확률 영역으로 나누어 각각 담당을 정하기로 했다.

- 콘텐츠 영역은 콘텐츠기획팀이 다루는 것이 자연스럽다는 데 양 팀이 공감했다.
- 확률 영역은 시스템기획팀이 관리하는 편이 일관된 기준을 유지하기에 좋다는 데 양 팀이 공감했다.
- 한 영역의 값을 고치려는 다른 팀은 해당 영역 담당 팀과 먼저 상의하는 방식으로 진행하기로 했다.

## 결정

- 콘텐츠기획팀이 데이터 테이블의 데이터(콘텐츠 영역)를 맡는다.
- 시스템기획팀이 데이터 테이블의 데이터(확률 영역)를 맡는다.

## 후속 작업

- 두 팀은 각자 맡은 영역의 범위를 데이터 테이블 안에서 확인하고, 경계가 애매한 항목이 있으면 목록으로 정리해 공유한다.
- 이번 결정 내용을 양 팀 구성원에게 알린다.
- 정리된 목록을 바탕으로 다음 회의에서 경계 항목의 담당을 최종 확인한다.
