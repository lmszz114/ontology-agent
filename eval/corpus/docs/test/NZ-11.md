# 우편 발송 업무 담당자 변경 안내

2026년 10월 15일 공지

사무실에서 외부로 보내는 실물 우편과 택배의 발송 담당자가 바뀝니다. 지금까지 이 업무를 맡아 온 김OO 님의 뒤를 이어, 10월 19일 월요일부터는 박OO 님이 발송 접수와 송장 작성을 맡습니다.

보낼 물건이 있는 분은 포장을 마친 뒤 받는 분의 이름, 주소, 연락처를 적은 메모를 함께 전달해 주세요. 등기나 착불처럼 발송 방식을 따로 정해야 하는 건은 접수할 때 미리 말씀해 주시기 바랍니다. 10월 16일 금요일까지 접수된 건은 김OO 님이 마무리합니다.

이 공지에서 말하는 우편은 종이 서류와 소포 같은 실제 배송물입니다. 게임 안의 우편함이나 게임 내 우편 기능과는 아무 관련이 없으니 혼동하지 않으시길 바랍니다.

발송 절차나 접수 방법에 궁금한 점이 있으면 박OO 님께 직접 문의해 주세요.
