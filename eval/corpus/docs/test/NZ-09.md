# 코스튬 아트 리뷰 회의

작성일: 2026-10-15

## 회의 개요
이번 회의는 가을 시즌 코스튬 세트의 콘셉트 아트를 검토하기 위해 열렸다. 참석자는 아트 디렉터 김OO, 콘셉트 아티스트 이OO, 기획 담당 박OO이다.

## 검토 내용
첫 번째 안건은 '달빛 무희' 세트였다. 김OO는 망토 자락의 색 대비가 약해서 먼 거리에서 보면 실루엣이 뭉개진다고 지적했다. 이OO는 안감에 밝은 청록 계열을 더하고 자수 문양의 선을 굵게 다듬겠다고 답했다.

두 번째 안건은 '서리 사냥꾼' 세트였다. 털 장식의 질감은 좋은 평가를 받았지만, 어깨 갑옷의 금속 광택이 지나치게 강하다는 의견이 나왔다. 박OO는 같은 계열의 기존 코스튬과 분위기가 겹치지 않도록 투구 모양을 조금 더 날카롭게 바꾸자고 제안했다.

## 결정 사항
- 달빛 무희 세트는 색 대비와 자수 선 굵기를 수정한 뒤 다시 검토한다.
- 서리 사냥꾼 세트는 광택을 낮추고 투구 형태를 바꾼 시안을 추가로 준비한다.
- 다음 리뷰는 2026-10-22에 열며, 수정본은 하루 전까지 공유한다.
