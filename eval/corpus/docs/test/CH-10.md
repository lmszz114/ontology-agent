2026-10-20, 확률 표기 문의 대응 채널

김OO(CS팀): 오늘 오전에 확률 표기가 이상하다는 문의가 또 들어왔어요. 공개 페이지 숫자가 틀린 거 아니냐는 내용이에요.

이OO(CS팀): 저도 비슷한 문의 받았어요. 틀렸다고 단정하는 분도 있고, 그냥 궁금해서 물어보는 분도 있고요.

박OO(운영팀): 일단 틀렸다고 보긴 이르죠. 오류인지 아닌지부터 확인해야 하는데, 어떻게 보면 돼요?

최OO(게임사업PM팀): 공개 페이지에 올라간 수치, 테이블 수치, 실제 결과 이렇게 세 가지를 비교해서 확인하면 돼요. 오류인지는 그 비교로 판단하고요.

박OO(운영팀): 아, 공개 수치랑 테이블만 맞춰 보면 되는 줄 알았네요.

최OO(게임사업PM팀): 그건 반만 보는 거예요. 둘이 같아도 실제 결과가 따로 놀 수 있으니까 결과까지 같이 봐야 해요.

김OO(CS팀): 그럼 제가 문의 주신 분들한테는 "확인 중"이라고만 안내하면 될까요?

최OO(게임사업PM팀): 네, 확인 중이라고만 해주세요. 원인 얘기는 아직 아무도 모르니까 추측으로 답하면 안 돼요.

이OO(CS팀): 저는 아까 공개 페이지가 갱신이 늦어서 그런 거 아닐까 생각했는데요.

최OO(게임사업PM팀): 그것도 지금은 추측이에요. 비교해 보기 전에는 어느 쪽도 말씀드릴 수 없어요.

이OO(CS팀): 네네, 접을게요. 입은 다물겠습니다.

박OO(운영팀): 공개 페이지 데이터는 어디서 관리하죠? 확인 요청을 어디로 보내야 할지 헷갈려서요.

최OO(게임사업PM팀): 저희 게임사업PM팀이 맡고 있어요. 공개 페이지 데이터 관련 요청은 이 채널이나 저희 쪽으로 주시면 돼요.

박OO(운영팀): 감사합니다. 방금 정리해서 스레드에 올려둘게요.

김OO(CS팀): 정정할 게 있어요. 아까 제가 "오전에 또 들어왔다"고 했는데, 같은 분이 두 번 보낸 거였어요. 문의가 늘어난 건 아닌 듯해요.

이OO(CS팀): 그럼 "또"는 빼야겠네요 ㅋㅋ

최OO(게임사업PM팀): 건수는 따로 정리해서 알려주세요. 비교 작업할 때 같이 볼게요.

박OO(운영팀): 점심 뭐 드실래요? 비교하다 보면 시간 훌쩍 갈 것 같은데.

김OO(CS팀): 저는 국밥이요. 오늘 날이 쌀쌀해서요.

최OO(게임사업PM팀): 국밥 좋죠. 비교 끝나고 먹을 수 있으면 좋겠네요.

이OO(CS팀): 그래서 비교는 누가 먼저 시작해요?

최OO(게임사업PM팀): 저희가 공개 수치와 테이블 수치부터 맞춰 볼게요. 실제 결과 쪽은 결과 나오는 대로 이 채널에 올리겠습니다.

박OO(운영팀): 알겠습니다. 결과 올라오면 CS팀 안내 문구도 그때 같이 맞춰 보죠.

김OO(CS팀): 넵, 그때까지는 "확인 중" 문구로만 안내하겠습니다.
