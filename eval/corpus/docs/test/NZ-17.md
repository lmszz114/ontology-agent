# 번역 용어집 업데이트 안내

2026년 10월 15일 자로 번역 용어집을 갱신했다. 이번 갱신은 퀘스트 대사와 아이템 설명에서 같은 말이 다르게 번역되던 항목을 정리하는 데 초점을 두었다.

먼저 '장애물'은 지형 위에 놓인 방해 요소를 가리킬 때 'Obstacle'로 통일한다. 같은 낱말이 대사에 섞여 나와도 이 표기를 따른다. '서버'는 퀘스트 NPC가 식당 종업원을 부를 때 쓰는 호칭이므로 'Waiter'로 옮기고, 다른 번역어를 쓰지 않는다. '원인 불명'은 괴질 퀘스트의 연출 문구에 한해 'Unknown Cause'로 적는다.

말투 규칙도 한 가지 손봤다. 의존명사 '것'으로 끝나는 설명문은 번역 단계에서 가능한 한 명사형으로 바꿔 쓴다. 고유명사와 지명 표기는 이전 판을 그대로 유지한다.

새 용어집은 번역 작업 폴더의 최신 파일을 기준으로 한다. 이전 판으로 작업하던 문서는 이번 주 안에 바뀐 항목만 찾아 고치면 된다. 수정이 필요한 항목이나 의견은 김OO에게 전달하면 다음 갱신에 반영한다.
