# 런북: 확률 표기 정정

작성: 시스템기획팀 / 작성일: 2026-10-15

## 이 절차를 여는 때

확률 표기에 문제가 있다는 신고나 감지가 들어오면, 먼저 원인이 무엇인지 분류한다. 원인이 다음 세 가지 중 하나로 확인되면 '확률 표기 정정' 절차를 연다.

첫째는 공개 페이지에 적힌 표기가 잘못된 경우다. 둘째는 확률 테이블에 들어 있는 값 자체가 틀린 경우다. 셋째는 확률 모듈의 로직에 오류가 있는 경우다. 이 세 가지는 현재까지 정리된 기준이며, 여기에 적히지 않은 상황이라도 확률 표기와 관련된 정정이 필요해 보이면 시스템기획팀과 상의해 절차를 열지 판단한다.

## 대응 단계

1. 원인을 분류한다. 위 세 가지 중 어디에 해당하는지 확인하고, 해당하는 항목을 기록에 남긴다. 원인이 확정되지 않았더라도 해당 가능성이 높으면 먼저 절차를 열고 기록을 보완한다.
2. 절차 개시를 기록한다. 개시 시각, 확인된 원인 분류, 문제가 의심되는 확률 항목을 사내 위키의 대응 기록에 적는다.
3. 올바른 값을 확정한다. 실제로 적용되어야 하는 확률을 확인하고, 현재 표기된 값과 어떻게 다른지 정리한다. 원인이 표기 오류인지 값 오류인지 로직 오류인지에 따라 확인할 자료가 달라지므로, 분류 결과에 맞춰 대조한다.
4. 정정 내용을 작성한다. 정정 전후의 값을 나란히 읽을 수 있도록 문장으로 정리하고, 담당자 검토를 받는다.
5. 정정을 반영한다. 정정된 내용이 이용자에게 보이는 표기에 반영되었는지 직접 확인한다.
6. 절차를 종료한다. 반영 결과와 종료 시각을 기록하고, 원인 분류별로 남은 후속 조치가 있으면 별도 항목으로 등록한다.

## 주의 사항

- 정정 문구에는 확정된 사실만 적는다. 추정은 넣지 않는다.
- 원인 분류는 진행 중에 바뀔 수 있다. 바뀌면 기록을 고쳐 적고 이전 분류도 이력으로 남긴다.
- 정정 반영 후에는 반드시 실제 표기를 다시 확인한 뒤 절차를 종료한다.
