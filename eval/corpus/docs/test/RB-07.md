# 런북: 확률 표기 정정

이 문서는 시스템기획팀이 2026-10-15에 작성한 확률 표기 정정 절차의 대응 방법이다. 확률과 관련된 문제가 확인되었을 때 이 절차를 열어야 하는 경우와 진행 순서를 정리한다.

## 언제 여는가

원인이 공개 페이지 표기 오류로 판단되면 확률 표기 정정 절차를 연다. 공개된 페이지에 적힌 확률 표기가 잘못된 경우가 여기에 해당한다. 확률 테이블 값 오류가 원인일 때도 같은 절차를 연다. 확률 모듈 로직 오류가 원인인 경우 역시 이 절차의 대상이다. 세 원인 중 어느 것이든 하나만 확인되면 충분하므로, 다른 원인까지 확인될 때까지 기다리지 않는다.

## 진행 단계

1. 문제가 접수되면 지금 공개된 확률 표기와 실제로 적용되는 확률을 나란히 놓고 비교한다. 어긋나는 항목을 모두 적어 둔다.
2. 어긋남의 원인이 위의 세 가지 중 무엇인지 구분해 절차 기록의 첫 줄에 쓴다.
3. 절차를 열고 정정이 필요한 항목과 정정 후 값을 확정한다.
4. 정정을 반영한 뒤 공개된 확률 표기와 실제 적용 확률이 일치하는지 다시 대조한다.
5. 일치를 확인하면 원인, 정정한 항목, 정정 전후의 값을 기록하고 절차를 닫는다.

## 주의 사항

원인을 구분하지 않은 채 정정부터 진행하지 않는다. 표기만 고치고 실제 적용 확률을 확인하지 않으면 같은 문제가 다시 발생할 수 있다. 정정 전후의 값은 반드시 기록으로 남긴다. 정정 후 대조 단계는 생략하지 않는다.
