# 장애 회고: 로그인 서버 오류 로그 폭증으로 접속이 막힌 두 번째 사건

작성일: 2026-10-15 / 작성: 서버개발팀

## 사건 개요

로그인 서버에서 오류 로그가 폭증하면서 이용자가 게임에 들어오지 못한 사건이다. 같은 유형의 접속 장애로는 두 번째라서, 이번에는 경과와 판단 근거를 빠짐없이 남겨 둔다. 증상은 '로그인 불가, 접속 장애'였고, 로그인 서버에서 드러났다.

## 타임라인

1. 이용자 쪽에서 로그인이 되지 않는다는 증상이 확인되었다.
2. 원인 후보를 좁혔다. 이런 증상에서 게임 로그인 서버 장애일 가능성은 중간 정도로 본다. 그래서 다른 후보와 나란히 두고 하나씩 따져 보았다.
3. 다른 타이틀의 로그인 상태를 확인했다.
4. 서버 오류 로그를 조회했다.
5. 두 확인 결과가 모두 게임 로그인 서버 장애 쪽을 가리켜 원인으로 판단했다.
6. 판단 직후 대응 절차 네 가지를 열었다.

## 확인한 근거

근거는 두 가지다. 먼저 다른 타이틀의 로그인은 정상이었다. 문제가 이 게임의 로그인 경로에 한정된다는 뜻이다. 다음으로 서버 오류 로그를 조회하자 로그인 서버에 이번 증상과 관련된 오류 로그가 쌓여 있었다. 게임 로그인 서버 장애가 원인이라면 나와야 할 결과가 두 확인에서 모두 나온 셈이다.

로그인 서버는 통합 계정 인증에 의존하므로, 인증 쪽에 문제가 생겨도 같은 증상이 날 수 있다. 이번에는 위 두 근거를 바탕으로 로그인 서버 자체의 문제로 판단했다.

## 원인

게임 로그인 서버 장애이며, 로그인 서버의 로직 쪽 문제다. 오류 로그가 폭증한 것도 이 문제가 겉으로 드러난 모습으로 보고 있다.

## 담당

로그인 서버의 로직은 서버개발팀이 맡고 있어, 이번 건도 서버개발팀이 처리했다.

## 조치

이 원인으로 판단되면 여는 절차를 그대로 열었다. 긴급 공지, 긴급 점검, 롤백, 원인 수정과 반영이다. 이용자에게 먼저 상황을 알리고, 점검과 롤백으로 접속을 복구한 뒤, 원인을 고쳐 반영하는 순서로 진행했다.

## 재발 방지

같은 증상이 다시 보이면 다른 타이틀 로그인 상태와 서버 오류 로그를 가장 먼저 확인한다. 이 두 확인으로 로그인 서버의 로직 문제인지 빠르게 가려낼 수 있다는 점이 이번에 다시 확인되었다. 오류 로그가 늘어나는 양상이 보이면 접속 장애로 번지기 전에 서버개발팀이 먼저 살펴보도록 한다. 로그인 서버가 통합 계정 인증에 의존한다는 점도 원인을 가를 때 함께 고려한다.
