# 장애 회고: 확률 모듈 배포 뒤 실제 결과가 테이블과 달라진 사건

작성일: 2026-10-15 / 작성: 서버개발팀

## 사건 개요

확률 모듈을 배포한 뒤 확률형 아이템의 실제 결과가 테이블에 적힌 수치와 다르게 나왔다. 증상은 '확률형 아이템 확률 표기 불일치'로 분류했다. 이 증상에서 원인 후보로 확률 모듈의 로직 오류를 꼽는 일은 드문 편이다. 그래서 초기에는 다른 후보부터 살폈다.

## 타임라인

1. 확률 모듈을 배포했다.
2. 배포 뒤 실제 결과가 테이블과 맞지 않는다는 점이 드러났다.
3. 확률 모듈은 게임 데이터 테이블에 의존한다. 그래서 테이블 쪽 문제가 모듈에 번졌을 가능성을 먼저 의심했다.
4. 공개 수치, 테이블 수치, 실제 결과를 나란히 놓고 비교했다.
5. 비교 결과를 근거로 원인을 확률 모듈의 로직 오류로 좁혔다.
6. 이어서 대응 절차를 열었다.

## 확인한 근거

확률 모듈의 로직 오류인지는 공개 수치, 테이블 수치, 실제 결과를 비교해서 가린다. 이 원인이면 테이블 수치와 공개 수치는 서로 같고, 실제 결과만 테이블 수치와 어긋난다. 이번에 나온 비교 결과가 정확히 그랬다. 공개한 수치는 테이블과 일치했고, 실제 결과만 테이블에서 벗어나 있었다. 테이블 자체가 틀렸다면 공개 수치와도 엇갈렸을 것이다. 이번에는 그렇지 않았으므로 테이블 문제 가설은 접었다.

## 원인

확률형 아이템 모듈, 곧 확률 모듈의 로직 쪽에 오류가 있었다. 테이블 값은 정상이었고, 그 값을 결과로 바꾸는 로직에서 어긋났다. 이 증상의 원인으로는 가능성이 낮게 보던 후보였다. 그 때문에 확인 순서에서 뒤로 밀린 점은 아쉬움으로 남는다.

## 담당

확률 모듈의 로직은 서버개발팀이 맡고 있다. 이번 건의 수정과 반영도 서버개발팀이 책임진다.

## 조치

로직 오류가 원인이면 네 가지 절차를 연다. 이번에도 모두 열었다.

- 확률 표기 정정: 잘못 알려진 확률 표기를 바로잡는다.
- 긴급 공지: 이용자에게 상황을 알린다.
- 긴급 점검: 문제가 된 결과가 더 나오지 않도록 서비스를 점검한다.
- 원인 수정과 반영: 로직 오류를 고쳐 서버에 반영한다.

## 재발 방지

- 이 증상은 로직 오류일 가능성이 낮아도, 공개 수치·테이블 수치·실제 결과 비교를 초기에 함께 돌려 후보를 빠르게 가른다.
- 확률 모듈은 게임 데이터 테이블에 의존한다. 테이블에 문제가 생기면 모듈에 영향이 가므로, 로직 오류와 테이블 문제를 구분해서 보는 습관을 유지한다.
- 확률 모듈의 로직을 바꾸는 배포 뒤에는 실제 결과를 테이블 수치와 대조하는 단계를 둔다.
