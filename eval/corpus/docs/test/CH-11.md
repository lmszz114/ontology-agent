# 슬랙 대화 CH-11

2026-10-20 월드보스 렉 관련 대화 기록

김OO(운영팀): 어제부터 월드보스 렉 제보가 계속 들어오네요. 원인 짚이는 분 계세요?

이OO(서버팀): 저는 서버 자원이 모자란 것 같다는 쪽입니다. 그냥 감이긴 한데요.

박OO(QA팀): 감이면 확인이 필요하죠. 자원 부족이 맞는지는 콘텐츠 일정이랑 맞춰 보면 알 수 있지 않을까요? 월드보스 시간이랑 공성전 시간이요.

이OO(서버팀): 맞아요. 두 콘텐츠가 같은 시간대에 겹치는지 보면 되겠네요. 그게 자원 쪽 확인 방법입니다.

최OO(개발팀): 저는 반대로 처리 로직이 비효율적인 거 아닌가 싶어요. 보스 쪽 코드가 좀 무거워 보여서요.

김OO(운영팀): 그건 어떻게 확인하죠?

최OO(개발팀): 서버 오류 로그를 조회하면 됩니다. 로직 문제라면 거기에 흔적이 남을 거예요.

박OO(QA팀): 아, 제가 아까 말을 헷갈리게 했네요. 정리하면 자원 부족은 일정 대조로, 로직 비효율은 오류 로그 조회로 보는 거죠?

최OO(개발팀): 네, 그렇게 두 갈래로 나눠서 보면 됩니다.

정OO(운영팀): 근데 월드보스랑 공성전이 겹친다고 단정하신 분은 없죠? 아직 가정입니다.

이OO(서버팀): 네, 단정 아닙니다. 저도 겹칠 수도 있겠다 싶은 정도였어요. 정정해 둘게요.

김OO(운영팀): 그럼 이OO님은 일정 대조, 최OO님은 로그 조회, 이렇게 나눌까요?

이OO(서버팀): 일정 대조는 제가 보겠습니다. 시간표부터 열어 볼게요.

최OO(개발팀): 로그는 제가 맡을게요. 다만 로그가 길어서 시간이 좀 걸릴 겁니다.

박OO(QA팀): 로그 보시다가 눈 아프면 말씀하세요. 저는 응원만 하겠습니다 ㅋㅋ

최OO(개발팀): 응원은 감사한데 같이 보면 더 좋겠네요.

정OO(운영팀): 그런데 오늘 점심 뭐 먹죠? 렉보다 이게 더 어려운 문제 같아요.

김OO(운영팀): 그건 월드보스보다 어렵습니다. 일단 결과 먼저 공유하고 먹읍시다.

박OO(QA팀): 그럼 결과는 이 채널에 올려 주세요. 자원 쪽과 로직 쪽 두 개 다 확인되면 그때 다시 이야기해요.

이OO(서버팀): 알겠습니다. 확인되는 대로 올릴게요.

최OO(개발팀): 저도 로그 먼저 훑고 올리겠습니다.
