# 장애 회고: 확률 공개 페이지 수치를 잘못 올린 사건

## 사건 개요

확률 공개 페이지에서 '확률형 아이템 확률 표기 불일치' 증상이 나타났다. 페이지에 올라간 공개 수치가 실제와 맞지 않았다. 사업PM팀은 이 증상의 원인을 추적해 공개 페이지 표기 오류로 판단하고 후속 절차를 진행했다. 이 문서는 2026-10-15에 사업PM팀이 그 경과를 정리한 회고다.

## 타임라인

증상이 확인된 뒤 가장 먼저 원인 후보를 좁혔다. 이런 증상에서는 공개 페이지 표기 오류가 원인일 가능성이 중간 정도라 우선 검증 대상에 올렸다. 확률 공개 페이지는 게임 데이터 테이블에 의존하므로 테이블 쪽 문제도 함께 의심했다. 이어서 두 가지 확인을 했고, 결과를 근거로 표기 오류로 결론 냈다. 그 뒤 정정, 공지, 수정 절차를 차례로 열었다.

## 확인한 근거

첫 번째 확인은 공개 수치, 테이블 수치, 실제 결과를 나란히 놓고 비교하는 일이었다. 공개 수치는 테이블 수치와 달랐다. 반면 테이블 수치는 실제 결과와 일치했다. 게임 안에서 실제로 돌아가는 값에는 문제가 없고, 밖으로 보여 주는 숫자만 어긋났다는 뜻이다.

두 번째 확인은 게임 데이터 테이블의 변경 이력 조회였다. 증상이 시작되기 전에 확률 테이블을 바꾼 이력은 없었다. 테이블이 바뀌어서 생긴 불일치라는 가설은 여기서 배제됐다.

## 원인

원인은 공개 페이지 표기 오류다. 확률 공개 페이지의 데이터 쪽 문제로, 페이지에 올라간 수치가 테이블 수치와 다르게 표기되어 있었다. 이 데이터는 사업PM팀이 맡고 있으므로 담당도 사업PM팀이다.

## 담당

확률 공개 페이지의 데이터는 사업PM팀 소관이다. 이번 건의 확인과 조치도 사업PM팀이 주도했다.

## 조치

공개 페이지 표기 오류가 원인일 때 여는 절차 세 가지를 모두 열었다.

- 확률 표기 정정: 잘못 올라간 수치를 테이블 수치에 맞게 바로잡는다.
- 긴급 공지: 이용자에게 표기가 틀렸음을 알린다.
- 원인 수정과 반영: 오류가 생긴 지점을 고쳐 반영한다.

## 재발 방지

확률 공개 페이지는 게임 데이터 테이블에 의존하는 만큼, 이후 비슷한 증상이 생기면 공개 수치, 테이블 수치, 실제 결과 세 가지를 비교하고 테이블 변경 이력을 조회하는 순서를 기본 점검 절차로 쓴다. 이 두 확인만으로 표기 오류와 테이블 문제를 빠르게 가를 수 있었다.
