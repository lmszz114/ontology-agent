# 온톨로지 장애 진단 에이전트

라이브 운영 경험을 바탕으로 MMORPG 운영 조직을 가정하고, 조직, 시스템, 절차를 온톨로지로 설계해 장애 제보의 원인과 담당 팀을 찾는 에이전트를 만드는 프로젝트입니다. 같은 지식을 통째로 넣는 방식, 문서 검색(RAG), 온톨로지를 같은 조건에서 비교할 예정입니다.

## 현재 상태

- 개발 중입니다. 구현 단계 M1~M3을 마쳤고, 다음 단계(현장 문서 묶음과 추출 에이전트)를 시작하기 전입니다.
- M1에서 만든 것: 온톨로지 스키마 제약, 정적 지식 시드(YAML), 시드를 Neo4j에 적재하는 기능, 온톨로지 조회 MCP 서버, 판정 근거 조회를 가상 데이터로 흉내 내는 모의 도구 MCP 서버
- M2에서 만든 것
  - 진단 에이전트(온톨로지 구성 C): 제보 접수 정리, 중복 판정, 심각도 계산, 원인 후보 순위와 판정 근거 확인, 담당 팀 결정, 절차와 조치 선택을 LangGraph로 처리합니다
  - 승인 게이트: 조치의 위험도를 보고 저위험은 자동 실행으로, 고위험은 승인 대기로 기록합니다. 실제 조치 실행은 하지 않습니다(시뮬레이션)
  - 실행 기록: LLM 호출, 도구 호출, 승인 요청을 토큰과 비용과 함께 Langfuse에 남깁니다
  - 평가 시나리오 형식과 검증기
- M3에서 만든 것
  - 비교 구성 A(기준 지식 전체를 텍스트로 넣는 방식): 같은 진단 에이전트에서 지식 공급자만 바꿔 돌립니다
  - 실행기(`python -m eval.runner`)와 채점기(`python -m eval.grader`): 실행마다 커밋, 모델, 단가를 결과에 남기고, 정답 라벨과 비교해 지표를 계산합니다
  - 개발용(dev) 시나리오 14건: 여러 채널 제보를 묶는 경우(2건)와 접수 증가로 등급이 오르는 경우(2건)를 포함합니다
- dev 결과 (2026-11-24 KST, claude-haiku-5-5, dev 14건, 3회 반복): 구성 A와 C 모두 원인 Top-1, 1차 담당 팀, 절차 일치율이 1.0이고 승인 요청 누락은 0건입니다. 반복당 비용은 C 0.067 USD, A 0.113 USD입니다. 비교표는 `eval/results/2026-11-24-m3-audit-dev-COMPARE.md`에 있습니다.
- 이 수치는 최종 결과가 아닙니다. dev 세트는 프롬프트와 코드를 고칠 때 쓴 세트라 결과가 좋게 나오기 쉽습니다. 고치기 전 실행에서는 두 구성 모두 틀린 사례가 있었고, 그 결과도 `eval/results/2026-11-24-m3-dev-COMPARE.md`에 그대로 남겼습니다. 구성 사이의 비교는 아직 손대지 않은 test 세트로 최종 실행에서 합니다.
- 원인을 확정하는 조건, 시나리오, 시나리오의 가상 데이터는 가정해서 만든 것이며, 실제 운영 데이터로 확인한 것이 아닙니다.
- 이 README는 임시본이며, 개발이 끝나면 실행 방법과 평가 결과를 포함해 다시 작성합니다.

## 만들 예정인 것

- 온톨로지: 가상 MMORPG 운영 조직의 팀, 역할, 시스템, 증상, 원인, 절차를 담은 그래프
- 진단 에이전트: 여러 채널로 들어온 장애 제보를 묶고, 원인 후보와 담당 팀을 근거와 함께 제시
- 승인 게이트: 저위험 조치는 자동 실행하고 고위험 조치는 사람의 승인을 요청 (대응 조치 실행은 시뮬레이션)
- 추출 에이전트: 장애 회고, 런북 같은 가상 현장 문서에서 지식 후보를 추출하고, 사람이 검수한 것만 온톨로지에 반영
- 비교 평가: 지식 전체 입력, 문서 검색(RAG), 온톨로지 방식을 같은 시나리오로 비교하고 결과를 평가 리포트로 공개

조직, 시스템, 문서, 시나리오는 모두 가정해서 만든 가상 데이터입니다.

## 사용 예정 기술

| 영역 | 기술 |
| --- | --- |
| 언어 | Python |
| 에이전트 프레임워크 | LangGraph |
| LLM | Claude API (기본 Claude Haiku 5.5, 비교용 Claude Sonnet 5.5) |
| 임베딩, 리랭크 | Voyage AI (voyage-4, rerank-3) |
| 그래프 DB, 벡터 검색 | Neo4j (그래프와 벡터 인덱스) |
| 도구 연결 | MCP 서버 |
| 실행 기록, 비용 기록 | Langfuse |
| 접수, 승인 | Jira Service Management, 슬랙 |
| 검수 화면 | Streamlit |
| 평가 리포트 | 정적 HTML, GitHub Pages |
| 회귀 테스트 | GitHub Actions |
| 실행 환경 | Docker Compose |

구현하면서 바뀔 수 있습니다.
